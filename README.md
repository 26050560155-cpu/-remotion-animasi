# Remotion + GitHub Actions

## Lokal
```bash
npm install
npm run dev      # buka Remotion Studio
npm run render   # hasil: out/video.mp4
```

## GitHub Actions
Push ke branch `main`, atau jalankan manual lewat tab **Actions → Render Remotion Video → Run workflow**
(bisa isi judul & subjudul). Video hasil render ada di bagian **Artifacts** pada run tersebut.
